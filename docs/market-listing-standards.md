# Guild Market — Listing Standards

*The rules every listing on the marketplace follows. Built from the failure modes documented across 1,386 eBay sold listings, 11,376 Instagram resale posts, and the 156-model reference catalog. Each rule exists because the open market got it wrong in a way we can point to.*

---

## 1. Identification — the listing must name the shoe correctly

1.1 Every listing is filed under a **catalog model** (brand + model from the Guild catalog). No free-text model names. If the shoe is not in the catalog, it goes to a review queue, not live.

1.2 **A style code never proves a model by itself.** Known shared codes, verified in our data:
- J702N — Asics JB Elite III *and* Aggressor 3 listings
- JY700 — Asics Cael V2.0 *and* V3.0
- 1081A030 — Asics Snapdown 3 *and* Split Second 9
- 1081A001 vs 1081A046 — two different codes both sold as "Aggressor 4"

Where a code is shared, the listing must be verified against the reference photos (silhouette, sole pattern, heel signature), not the code.

1.3 The **interior size label photo is mandatory** (see §4). It is the single best identity document a shoe has — and the first thing fakes get wrong.

1.4 **No cross-titling.** A title names the actual model only. Keyword-stuffing other models ("Inflict Kolat Freek style") is prohibited — on eBay this pollution is the main reason search fails.

1.5 Generation ambiguity is declared, not guessed. Known traps:
- Every "Tech Fall" listing in our sample was actually a Tech Fall 2.0 in design and code, whatever the title said.
- "Combat Speed IV" *is* Combat Speed 4 (Roman-numeral branding on the same shoe).
- Generic "Cael" or "Takedown" listings that cannot be tied to a generation are listed as the base model with an **"generation unverified"** tag — never upgraded to a rarer generation.

1.6 Boarding-school rule analog for shoes: a shoe is what it *is*, not what the seller calls it. Platform identification (photo match against the catalog) overrides the seller's title on conflict, with the seller notified.

## 2. Condition grading — one scale, photo-proven

Every listing carries exactly one grade. The grade must be defensible from the listing's own photos.

| Grade | Standard |
|---|---|
| **New** | Never worn on a mat. Tags and/or box present, or seller can show unworn soles. "New (Other)" eBay-style ambiguity does not exist here — if it was worn, it is not New. |
| **Like New** | Worn 1–3 times. Sole bumps/grippers fully intact, no visible upper wear, no odor treatment needed. |
| **Good** | Honest training wear. Sole grip still functional, uppers intact, no repairs. Most of the resale market lives here. |
| **Worn** | Heavy wear, thin or smooth sole spots, cosmetic damage, or a stated flaw. Fully usable as a beater or a sole-swap candidate — and priced like one. |

2.1 **Sole condition is stated separately** (full grip / partial / smooth in spots / end-of-life), because sole state drives value more than uppers do. A "defective stain" pair is not New at any price — seven such pairs moved on eBay as "New (Other)" in our sample.

2.2 Grades are checked against photos at review. A listing whose photos contradict its grade is corrected or removed before it sells, not after a dispute.

## 3. Mandatory disclosures — the tags that can never be omitted

A listing must carry every applicable tag. An omitted tag that a buyer discovers is automatic grounds for a full refund plus seller strike.

- **SOLE SWAPPED** — soles replaced (a whole trade on IG/eBay; legitimate, valuable work — when disclosed)
- **REPAIRED** — stitching, re-gluing, patch, or structural repair
- **CUSTOM PAINTED / CUSTOMIZED** — any paint or colorway alteration (the Schmidt EX-EO pattern: genuine shoe, aftermarket finish)
- **CUSTOM BUILD** — a bespoke build, including builds on another model's upper (the "Cronin 88" problem: pairs sold as handcrafted 88s that were custom builds on CB2 uppers)
- **REPLICA** — see §5
- **MISMATCHED PAIR** — the two shoes differ in colorway, size, or production run (we captured a "Greco Supreme" reference pair that was one pink/green shoe and one black/white)
- **NO BOX / NO TAGS** — where the grade or model normally implies them
- **DISPLAY ONLY / COLLECTOR** — dry-rotted or fragile vintage that should not be wrestled in (dry-rot soles are common on 1990s Adidas)

## 4. Photo standards

4.1 Required angles, seller's own photos only:
1. **Lateral** (outside of the shoe)
2. **Sole / tread**
3. **Top-down**
4. **Heel** — mandatory on models with a heel signature or logo (most Nike Freeks and Asics Caels; it is how fakes are spotted)
5. **Interior size label**

4.2 No stock photos, no manufacturer renders, no other sellers' photos, no watermark-obscured images. A listing photo taken from Instagram or eBay is removed on sight — photo theft is the IG market's standard scam.

4.3 One lateral per major colorway for multi-colorway listings; the colorway name comes from the catalog, not the seller's invention.

## 5. Replicas and fakes

5.1 A replica may **never** be listed as, or confused with, the genuine model. This is the EX-EO rule: genuine EX-EOs and openly-titled "(reps)" EX-EOs trade side by side on eBay at similar prices ($140–$155 for the reps from one high-volume seller), and the rep's own size-label photos are the tell.

5.2 **Ruled (Matt, 17 Nov 2026):** replicas are allowed only in a clearly separated **Replica/Tribute category** with the REPLICA tag locked on, with zero tolerance for miscategorization — the demand demonstrably exists, it is currently served by the least honest sellers, and a labeled category starves the pass-off market. One strike for listing a replica as genuine.

5.3 Known-fake tells are maintained as a living appendix (rep label fonts, tag formats, sole molds), seeded from the catalog work — starting with the EX/EO reps' label and tag photos.

## 6. Pricing integrity

6.1 Listings show the platform's **sold-price reference** for the model (from the Guild price index: eBay sold + verified IG sales, size/condition-adjusted where the data supports it) next to the ask. Asks on eBay run 2–5× sold prices; the reference is the antidote.

6.2 A completed sale records the **actual transacted price**, never the ask. (eBay's Best Offer display — list price shown as if it were the sale price — is the practice this marketplace exists to replace.)

6.3 Trade listings ("looking for trades") state a trade value on the same reference basis.

## 7. Authentication tiers

- **Standard** (most listings): catalog photo-match + label photo review before the listing goes live.
- **Verified** (grails, rare tier, and any sale above the threshold in 7.1): expert review of the full photo set against reference angles before funds release.
- **7.1 Ruled (Matt, 17 Nov 2026): the Verified threshold is $500.** Only the true grail tier gets the expert pass; everything below moves at standard photo-match speed. (Draft had suggested $300.)

7.2 Sellers of record: repeat sellers carry their disclosure history. An upheld non-disclosure claim is visible on the seller's profile.

## 8. What gets a listing removed

Cross-titled or misidentified model after notice · grade contradicted by photos · missing mandatory disclosure · stolen or stock photos · replica listed as genuine · a shoe the catalog cannot identify and the seller cannot document.
