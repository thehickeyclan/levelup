# Brand logos

Place image files here so the header and homepage display correctly.

## Required

| File | Use |
|------|-----|
| **guild-mark.png** (or `.svg`) | Header, link previews, compact UI — the G mark without wrestlers |
| **guild-logo-hero.png** (or `.svg`) | Homepage hero only — full lockup with wrestlers in the G |

Legacy files `guild-g.png` and `guild-bronze.jpg` may remain as backups.

## Optional

| File | Use |
|------|-----|
| **nc-united.png** | State org logo (tenant config `stateOrgLogo`). |

Path in config: `config/tenants.ts` → `logo` and `stateOrgLogo`. Change there if you use different filenames.
